# Yuky 个人作品集

奶油白、墨黑和薄荷绿的响应式设计师作品集。包含 3D、全案设计、海报、Logo、形象设计、UI 和字体设计七个分类，按类别纵向展开作品，左侧竖向导航可跳转对应栏目。支持搜索、作品详情和合作联系方式。

## 启动

```sh
npm install
npm run dev -- --port 5173
```

打开 http://localhost:5173。`npm run build` 生成可部署的 `dist/` 静态文件；`npm run preview` 预览构建。

## 添加自己的作品

页面底部「管理作品」可以上传封面、填写名称与作品介绍、隐藏示例，以及修改名字、首页介绍、邮箱、微信。

这些修改保存在当前浏览器的 IndexedDB 中，同一网址刷新后保留，不会自动同步到其他浏览器或公开站点。请在「备份」标签导出 JSON，避免清理浏览器后丢失内容。导入备份可以在另一浏览器恢复。

要让所有访客看到真实作品，把图片保存到 `public/works/`，并修改 `src/main.js` 中的 `defaults` 和初始 `profile` 数据后重新构建部署。当前没有服务器管理后台或账号认证。前台「管理作品」仅影响访问者自己的浏览器。

当前九个项目明确标为概念作品，并非 Yuky 的真实履历。联系方式未编造。SVG 示例由 `scripts/create-demo-assets.mjs` 生成，执行它可重建示例图。

## 图片生成记录

3D 示例封面使用内置 imagegen 工具生成，已保存在 `public/works/soft-objects.png`。生成提示见 `assets/imagegen-prompt.txt`。其他海报、标识、品牌和界面示例为站点原生 SVG。

## 立体作品预览

点击 Soft Objects 或 MORI · 森日，可打开原生 Three.js 立体预览：拖动旋转、滚轮或双指缩放、左右转动、复位、三种配色和线框查看。键盘方向左右、加减号和 Home 也能操作模型。可随时切换回原来的平面图。

两个模型是根据本站概念作品制作的示例模型，并非从图片自动提取的真实设计文件。模型只在打开详情时加载，关闭时释放图形资源；不支持 WebGL 的浏览器可以查看平面预览。原有本地封面上传功能保持不变，尚未增加自定义模型文件上传或第三方上传。
